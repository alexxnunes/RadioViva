# RadioViva 📻🇧🇷

Applet moderno, completo e de alta performance para o painel do Linux Mint (Cinnamon), dedicado às emissoras de rádio de todo o Brasil.

## Principais Recursos
- **100% Brasil**: Mais de 1.600 rádios organizadas por todos os 26 Estados + DF e Gêneros.
- **Interface Moderna**: Player card integrado no menu da barra com exibição do nome da música em tempo real.
- **Busca Instantânea**: Pesquise por nome, cidade ou estado direto no menu sem abrir janelas extras.
- **Scroll de Volume**: Ajuste o volume girando o scroll do mouse sobre o ícone do painel.
- **Gravação ao Vivo**: Grave suas músicas e programas favoritos diretamente em MP3 na pasta `~/Música/RadioViva`.
- **Sleep Timer**: Programe o desligamento automático para dormir ouvindo rádio.
- **Motor MPV IPC**: Leve (< 15MB RAM), resiliente e com suporte a todos os formatos de áudio.

## Stack Tecnológica
- **JavaScript (GJS / GNOME Shell Toolkit - St / Clutter)**: Interface nativa do Cinnamon Applet.
- **MPV (Daemon C / IPC JSON Socket)**: Motor de reprodução e metadados em tempo real.
- **Python 3**: Scripts de sincronização e validação das rádios brasileiras.
- **CSS3**: Tema visual integrado ao Cinnamon / Linux Mint.
